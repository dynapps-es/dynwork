## Claude Agent through Governance, and Dynwork on Linux 🐧

- 🤖 **Claude Agent with your own Claude subscription:** while you are signed in to Governance, Claude Agent stays in
  the model picker and its calls go through your organization's Governance gateway, which records them under your
  account and applies its policies. Your Claude plan covers the usage. Sign in to Claude Code once with
  `claude auth login` to use it.
- 🐧 **Linux:** a `.deb` for Debian and Ubuntu and an AppImage for other distributions, both for x64.
- 📱 **Remote model choice:** a model picked on Dynwork Mobile now replaces the one in the desktop composer.
- 🔌 **Connect dialog:** it no longer offers providers your organization blocks.
- ♻️ **Updates apply in full:** installing a new Dynwork now also replaces the background service the previous version
  left running, so everything new in a release takes effect the first time you open it.

### Known limitations

- The installers are not signed by Apple or Microsoft, so the system warns you the first time (see below).
- macOS and Linux do not update themselves: download the new file from the latest release. Windows updates itself.
- Claude Agent through Governance needs an instance on Governance 0.81 or later that offers the Claude subscription
  models, and a Claude Code signed in with `claude auth login`. An API key or token set for Claude Code replaces that
  login and the gateway refuses the call.
