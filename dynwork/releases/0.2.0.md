## Scheduled tasks, Dynwork in your language, and a new look ⏰

Dynwork can now run tasks for you on a schedule, on your computer, with the same agents, models and connectors you use
in a chat. Your tasks follow you to your other computers through Governance, and Dynwork's own screens now speak
Spanish, French and Dutch.

- ⏰ **Scheduled tasks:** a new **Scheduled** section in the sidebar. Give a task its instructions and when it repeats
  (or only when you run it), then choose its model, its permissions (**Ask me** or **Don't ask**), a time limit, the
  connectors it may use, whether a missed run is made up, and when to tell you. Each run opens as a conversation you
  can read and continue.
- 💬 **Managed from a chat:** **Create with Dynwork** writes a task with you, and in any conversation you can ask to
  list, change, pause, resume, run or delete your scheduled tasks. Every change waits for you to confirm it above the
  composer.
- 🔄 **On all your computers:** while you are signed in to Governance, your scheduled tasks sync to your other
  Dynwork computers and appear in Governance under Account, where you can pause, resume or delete them. Each task runs
  only on the computer that owns it. A task prepared for you in Governance is picked up by the first Dynwork you open.
- 🌍 **Spanish, French and Dutch:** Dynwork's own screens follow the language you choose in Settings.

### A refreshed interface 🎨

- 🪟 **macOS sidebar glass:** on macOS the sidebar shows the system's translucent material, like other Mac apps.
- 🔤 **Readex Pro:** the Dynapps font is now the default, with all its weights. You can still pick another font in
  Settings.
- 🎯 **One primary color:** every main button uses the same Dynapps primary, and the dark theme is now blue-grey
  instead of black.
- 💬 **Your messages stand out:** what you write sits in a light primary bubble, in light and dark themes.
- 🏷️ **Clearer badges and alerts:** states and warnings use clearer colors, and badges are square with rounded corners.
- 🔠 **Larger titles:** page titles are bigger and easier to scan.
- 🕒 **Scheduled in the sidebar:** a clock marks the new section, and a **+** appears on hover to start a new task
  straight away.
- ✅ **Confirmations above the composer:** when the agent wants to create, change, run or delete a scheduled task,
  you approve it in the same place you approve its other actions.
- 🧩 **Consistent controls:** the new screens use the same selects, switches and menus as the rest of Dynwork, laid
  out like Settings.

### Known limitations

- A scheduled task runs only while Dynwork is open on the computer that owns it. A run missed while it was closed is
  made up when it opens again, if the task allows it and the run is recent.
- A change made in Governance or on another computer reaches Dynwork within five minutes, or at once while remote
  control is on.
- Some texts that come from OpenCode itself are still in English in the new languages.
- The installers are not signed by Apple or Microsoft, so the system warns you the first time (see below).
- macOS and Linux do not update themselves: download the new file from the latest release. Windows updates itself.
